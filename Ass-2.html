Part D: Debugging Challenge

Common Errors and Corrections

  1. Incorrect: Missing closing table tag.
    Correct: Always close with </table>.
  2. Incorrect: Using colspan="2" but forgetting that it occupies two columns.
    Correct: Adjust the remaining cells accordingly.
  3. Incorrect: Using rowspan="2" without removing the next row's occupied cell.
    Correct: Do not add another cell in that position.
  4. Incorrect: Missing border-collapse.
    Correct: Use border-collapse: collapse.
  5. Incorrect: Fixed-width layout on mobile.
    Correct: Use CSS media queries and flexible layouts.
